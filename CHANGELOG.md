# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-06-13

### Added
- **Core Systems**:
  - Full progression through 8 tiers (Mud to President).
  - Living World system with World Events and Market Sentiments.
  - Narrative Framework with branching choices and persistent flags.
  - Rival AI system with leaderboard and challenges.
  - Legacy Evolution (Roguelite meta-progression).
- **Gameplay**:
  - Over 40 unique hustles with level-based upgrades.
  - 30+ interactive minigames.
  - Specialization system for late-game builds.
  - Presidency management mode (Approval, GDP, Cabinet).
- **Technical**:
  - Centralized Math and Advancement engines.
  - Zustand-based state management with persistence.
  - Comprehensive documentation (Architecture, Design, Content Guides).
  - High-stakes large spend confirmation modal.
  - Share Card generation for run summaries.
